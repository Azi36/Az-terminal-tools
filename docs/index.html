##它能干什么
终端

一台服务器，一个标签

终端、文件、隧道、配置都在这个标签里翻页。切走的终端还活着，回来接着敲。

  • Rust 引擎（russh）+ xterm.js，真 PTY 真颜色
  • 密码、密钥、2FA 动态口令都能登
  • 看到乱码就把编码从 UTF-8 切成 GBK，不用重连
  • 掉线自己接回来，会话输出能存成日志
  • 配色 6 套、字号 4 档，回滚 5000 行

文件

传一半断了，接着传

左本地右远程，走的是终端那条连接的子通道，不用二次输密码。

  • 断点续传；传到一半也能喊停，半截文件自动收干净
  • 重名先问你：覆盖 / 跳过 / 续传，不闷声盖掉
  • 目录同步：只推新的和改过的，不删对面的东西
  • 几个文件同时传，速度和剩余时间实时在跳
  • 整个目录拖进来直接传；上万个文件的目录也不卡

编辑

远程配置文件，点开就改

老流程是下载 → 本地改 → 记得上传 → 忘了上传 → 改了半天没生效。这儿 Ctrl+S 直接写回原路径。

  • 不落临时文件、不叫外部编辑器、不用手动上传
  • GBK 的文件按 GBK 存回去，不会悄悄变成 UTF-8
  • 原来是 CRLF 就还它 CRLF，改一行不会变成整个文件都动过
  • 存之前查一眼有没有被别人改过，有就停下来问你
  • 查找替换、跳行、行号，顺手 chmod

隧道

内网的东西，本机直接连

数据库只对服务器开放？转发一下就好。走的还是那条已经认证过的连接，不用再登录一次。

  • 本地转发（-L）：本机连 5432，等于服务器在连内网库
  • 动态代理（-D）：本机一个 SOCKS5，浏览器挂上去
  • 远程转发（-R）：服务器开个口，落到你本机的服务
  • 跳板机：先过堡垒机再连目标机，等同 ProxyJump
  • 断开会话时自动全部收掉，不留半开的口子

##凭据这块，说清楚
🔐

密码进系统钥匙串

Windows 凭据管理器 / macOS Keychain。我们自己的配置文件里一个字节明文都没有，前端代码也拿不到——它只能问"这条记过没有"。

🔑

私钥只存路径

私钥内容连接时才读，不落盘、不进日志。密码短语要不要记，你自己勾。

🖐️

指纹用标准 known_hosts

跟系统 ssh 共用 ~/.ssh/known_hosts。头一回连自动记下不打扰你，指纹变了才拦住报警——那才是该停下来看一眼的时候。

🚫

不经手你的流量

你的电脑直连你的服务器，中间没有我的服务器。所以它才能一直免费。

导出的备份里不含密码——导成明文就把上面这一整套作废了。换机器第一次连再输一次，就这一次。

##几个问题
为什么免费？以后会收费吗？

所有连接都是你的电脑直连你的服务器，我这边不经手流量，也没有账号系统要养。没有服务器成本，收费没道理。不收。

和 Xshell / Xftp / Termius 比呢？

日常那部分追平了：敲命令、传文件、改配置，加上端口转发、跳板机、2FA、断点续传、目录同步。还差分屏广播和 FTP。区别在于这些都不锁付费墙，也不用注册。

数据会同步到云上吗？

不会。连接配置、指令、备忘全在本机。想换机器就导出成一个 JSON 自己搬——里面不含密码。

会偷偷连网吗？

只有一件事：开起来几秒后问一句「有没有新版」。就一个 GET，不带身份、不上报任何东西，设置里能关。

支持 Linux 吗？

Tauri 本身支持，源码自己构建能跑，只是 CI 里目前只出 Windows 和 macOS 包。

能自己改吗？

MIT 协议，随便改随便分发。前端 React + TypeScript，内核 Rust，构建命令在 README 里。
