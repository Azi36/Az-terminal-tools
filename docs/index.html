##凭据这块，说清楚

不要账号、不传云、不过期、不锁功能 —— 这几条是设计目标，不是"暂时还没做"。

🔐

密码进系统钥匙串

Windows 凭据管理器 / macOS Keychain。我们自己的配置文件里一个字节明文都没有，前端代码也拿不到。

🔑

私钥只存路径

私钥内容连接时才读，不落盘、不进日志。密码短语要不要记，你自己勾。

🖐️

指纹用标准 known_hosts

跟系统 ssh 共用一份记录。头一回连自动记下不打扰你，指纹变了才拦住报警。

🚫

不经手你的流量

你的电脑直连你的服务器，中间没有我的服务器。所以它才能一直免费。

全程唯一一次主动联网，是开起来几秒后问一句「有没有新版」——就一个 GET， 不带身份、不上报任何东西，设置里能关。

##还差什么

日常那部分基本齐了。老实说还差这三样，做完会写在更新说明里。
