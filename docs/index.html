##你的密码，我拿不到
🔐 密码交给系统管Windows 凭据管理器、macOS 钥匙串。我自己的配置文件里一个明文都没有
🔑 私钥只记个路径内容要连的时候才读，不落盘，也不写进日志
🖐️ 指纹用 known_hosts跟系统 ssh 共用一份。头回连自动记下，变了才拦你
🚫 流量不过我这儿你的电脑直连你的服务器。所以它才能一直免费

全程只主动联一次网：开起来几秒后问一句有没有新版，就一个 GET，不带身份，设置里能关掉。

##下载

包是 GitHub Actions 直接构建出来的，构建记录谁都能去翻。十几兆，界面用系统自带的 webview。

Windows · .msi macOS · Intel 与 Apple 芯片通用 Linux · 源码可构建，暂不出包
Windows.msi 安装包 macOS.dmg 通用包

没做代码签名（个人证书一年好几百，先省了）。Windows 首次打开会提示「未知发布者」， macOS 去「系统设置 → 隐私与安全性」点「仍要打开」。
